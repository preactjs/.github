# AI contribution policy

Preact follows the [Human Voice policy, version 1.0.0](https://ai-policy.dev/policies/human-voice/1.0.0/).

Write issues, pull request descriptions, and comments in your own words. When you report a bug, tell us what you observed. When you propose a change, explain why you chose it. Your grammar and spelling don't need to be perfect.

You're welcome to use AI tools to explore the codebase, try ideas, or write code and tests. Before submitting a change, review it, test it, and make sure you can explain how it works. You're responsible for everything you submit and for following the repository's contribution guidelines.
